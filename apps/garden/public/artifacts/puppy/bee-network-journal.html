01 · les familles

Sept familles, très inégales

La famille dit ce que le mémo documente. Le pipeline d'investissement porte presque tout le journal : les votes à eux seuls dépassent la moitié des rattachements. Cliquez une famille pour lire ses types.

02 · les types

Choisir le type avant d'écrire

Le type fixe trois choses : le modèle de page, les propriétés obligatoires, et si le mémo exige une startup.
