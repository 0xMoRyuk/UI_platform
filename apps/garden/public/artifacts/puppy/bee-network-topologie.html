01 · la carte

Autour de la fiche

Le rayon dit combien de relations séparent une base de Startups Pool ; l'angle, son contexte. L'anneau coloré autour d'une base est sa signature : la part de chaque famille dans ses propriétés. Les fils prennent la couleur de la famille qu'ils transportent. Cliquez une base, ou une famille.

Taille d'un nœud : nombre de fiches (échelle logarithmique). Contour plein : à garder ; tiret : à investiguer ; estompé : pruned. Sans anneau : base hors Schema Contracts.

02 · les contextes

Dix contextes, une base de plus à chaque fois

La taxonomie range chaque base dans un contexte : le rôle de la base qui porte la propriété. Sous chaque base, sa signature de familles ; un clic la retrouve sur la carte.
